# CNYOS Production Gate Evidence Matrix

Status: **fail closed**. Source presence, a green unit test, a Netlify `Ready` state, a dashboard screenshot or an unsigned checklist cannot pass a gate.

Every pre-deployment gate must be represented in `PRODUCTION_RELEASE_ATTESTATION_JSON` for the exact candidate commit. The final owner notification occurs only after the same commit has a successful production-promotion run, production-deployment run and post-deploy public attestation.

## External sign-off boundaries

The implementation team must not self-issue the independent security, privacy/legal or clinical-governance approvals. Those artifacts must identify the reviewer, scope, date, exact release commit, findings and unresolved-blocker count.

## Completion and notification

1. The protected production attestation must contain all 16 gates in the exact order defined by `release-readiness.json`, each with `status: passed`, exact `commit`, retained `artifact`, `verifiedAt` and `verifiedBy`.
2. The `Production promotion gate` workflow must succeed for that exact commit.
3. The `Production Netlify deploy` workflow must succeed for that exact commit.
4. The `Production post-deploy attestation` workflow must verify the public runtime against the exact commit/tree.
5. Only after steps 1–4 succeed may GitHub mention `@apisarit`, record the workflow evidence and close Issue #11.

Real patient data remains blocked until the post-deploy attestation succeeds.
